## 🛠️ Функционал Панели Администратора (`admin.html`)

### 1. 📦 Управление и Отслеживание Заказов (Orders Management)
* **Таблица заказов в реальном времени**: Номер заказа (`DX-PG400-XXXXXX`), дата, Unique ID клиента, Telegram контакт, фасовка (30, 60, 90, 120 капсул) и количество (2–100 шт), сумма в **LFT Crypto**.
* **Смена статуса в 1 клик**:
  * `Новый (Ожидает LFT)`
  * `Оплачен (LFT)`
  * `В пути / Курьер`
  * `Выдан / Доставлен`
  * `Отменен`
* **Назначение локации доставки**: для каждого заказа можно ввести точный адрес, тайник, координаты GPS или инструкции курьеру.
* **Фильтрация и поиск**: по статусу, номеру заказа, Unique ID клиента или @telegram нику.
* **Создание заказов вручную**: добавление заказов, поступивших напрямую из Telegram.

### 2. 📍 Управление Гео-Локациями Доставки & Дропами
* Добавление и редактирование зон доставки: Город/Регион, Район/Сектор, GPS-координаты тайника, комментарий для курьера.
* Зоны и координаты можно привязать к любому заказу при его комплектации.

### 3. 🤖 Шлюз Telegram Бота
* **Настройка бота**:
  * Поле для ввода **Telegram Bot Token** (токен от `@BotFather`).
  * Поле для **Telegram Bot Username** (например `@DragonX_Capsules_Bot`).
  * Поле для **Chat ID Оператора** (для мгновенных push-уведомлений о поступивших заказах).
* Синхронизация: при сохранении данных в панели администратора витрина магазина сразу начинает ссылаться на вашего нового бота.
* Готовые команды для интеграции: `/start`, `/orders`, `/location`, `/status`.

### 4. 👥 База Клиентских Unique ID
* Просмотр всех зарегистрированных клиентов, их пожизненных буквенно-цифровых кодов (`DRGX-XXXX-XXXX`), истории покупок и персональной скидки.

### 5. 💰 Управление Ценами в LFT Crypto & Лимитами Партии
* Возможность оперативно корректировать стоимость фасовок (30, 60, 90, 120 капсул).
* Регулировка минимального (2 шт) и максимального (100 шт) лимита заказа.
